# Northstar documentation

Keep the documentation small and authoritative:

- [`../NORTHSTAR.md`](../NORTHSTAR.md) — product direction, MVP boundary,
  priorities, and operating rules.
- [`architecture.md`](architecture.md) — system boundaries, data flow,
  deployment, and known technical gaps.
- [`decisions.md`](decisions.md) — durable product and technical decisions.
- [`research/`](research/) — clearly labeled research and synthetic evaluations.

The root [`README.md`](../README.md) remains the quick-start guide. Add a new
document only when its subject cannot be kept clear in one of the files above.
